## Planned development sequence

1. Continue deepening the existing Angular and TypeScript foundation.
2. Build backend fundamentals with Node.js and NestJS.
3. Develop practical PostgreSQL data-modeling and query skills.
4. Add Redis, queues, and asynchronous processing patterns.
5. Build deployment fundamentals through Docker, Linux, and networking.
6. Study AWS architecture and system design.
7. Explore Go after the backend and platform foundation is established.
8. Study Web3 fundamentals before framework-specific development.
9. Use React with viem and wagmi for relevant Web3 applications.
10. Learn Solidity after the application and protocol foundations are clear.
11. Consider Rust or Solana only when a concrete project justifies the cost.

AZ-900, GH-900, AWS Cloud Practitioner, or Cloud Digital Leader.
